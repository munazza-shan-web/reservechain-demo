# ReserveChain.io Contest Prototype

A hosted-ready, responsive working draft created for the ReserveChain.io contest brief.

## Included
- Homepage with mandatory prelaunch disclosure
- Copper Powder program page
- Nickel Wire program page
- Asset Registry preview
- Sample Digital Asset Passport
- Verification / future Proof-of-Reserves concept
- Tokenization architecture page
- Enterprise services, documents, roadmap and FAQ
- Functional demo waitlist using local browser storage
- CMS/admin structure prototype
- Technical architecture page
- Development schedule

## Important
This is a contest prototype only. It intentionally does **not** invent or claim real quantities, valuations, custodians, insurers, laboratory certificates, token prices, contract addresses, ownership rights, liquidity, returns or confirmed Proof-of-Reserves. Wallet, purchase, Proof-of-Reserves and redemption functions remain inactive conceptually until authorized.

## Run
Open `index.html` locally, or publish the folder to GitHub Pages / Netlify / another static host.


## Visual Direction
Premium institutional design combining Swiss-fintech restraint with industrial-metals cues. The prototype deliberately avoids speculative crypto styling and presents all unverified program data as illustrative or pending.
